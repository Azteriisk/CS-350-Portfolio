CS 350 Milestone Three Guidelines and Rubric

Overview

In this lab, you will use an editor of your choice to create the Python code necessary to control the LED from the circuit you built in previous assignments. During this milestone, you will use a method of your choice to edit the code template provided and test your code on your circuit. You will then proceed to use it for debugging. You will build on this circuit and these processes throughout this course. You will also be able to learn more about the timers and interrupts. Your objective in this assignment is to blink the red and blue LEDs in a pattern that communicates Morse code messages to anyone viewing the LEDs. You will use a state machine that creates a pattern of blinking lights from the LEDs. This pattern should contain a message in Morse code. When a button is pressed, the Morse code message of the blinking LEDs should change.

Directions 

For this milestone, you will use the Milestone Three Input With Buttons Lab Guide linked in the Supporting Materials section to continue the development of your circuit. While this document was written for a Windows interface, the tools can also be used on Mac or Linux. 

Specifically, you must address the following rubric criteria:   

  1. Develop Python code to control the LEDs to flash a Morse code message using red (dots) and blue (dashes) LEDs. Ensure the code operates the LEDs in the specified pattern and intervals (dot: 500ms, dash: 1500ms, and the like) and can change the message upon button press without interrupting the current message.
  2. Create a functioning state machine that controls the LED patterns in Morse code and transitions smoothly between states. Implement state transitions based on button presses to switch between messages while maintaining the state machine’s logic.
  3. Integrate the 16x2 display to show the Morse code message or other relevant information. Demonstrate how to use the display to provide feedback or debug information when running the application.
  4. Discuss the lab questions. Address all the questions thoroughly and thoughtfully, with supporting evidence from your work.
  5. Apply coding best practices in formatting, commenting, and functional logic.

What to Submit

To complete this project, you must submit:  

  • A .py file (Python script file) that shows the source code you developed
  • A short video (about 2 minutes) of your device as it runs the code 
  • A Word document with answers to the questions from the Milestone Three Input With Buttons Lab Guide
  • A state machine diagram completed using draw.io and exported in PDF format
