CS 350 Milestone Two Guidelines and Rubric

Overview

During this milestone, you will use the code template provided to edit, test, and debug Python code to control the LED from the circuit you created on the solderless breadboard beginning in the Module One assignment. You will build on this circuit from the serial port of the Raspberry Pi and these processes while learning more about the UART and GPIO drivers. This work will build on the concepts you learned during your activities in the zyBook this week.  

Your goal for this milestone is to modify the code template provided to turn on an LED when a user types ON into the control program running in a terminal and to turn off the LED when a user types OFF. Additionally, the application must exit cleanly when the user types EXIT or QUIT into the control program. This will demonstrate how to control the physical device from code running across the serial connection to the Raspberry Pi. This is also an example of how many real-world control systems operate in a client-server model.

Directions 

During this milestone, you will use the Milestone Two GPIO UART Lab Guide linked in the Supporting Materials section to develop, debug, and use code to control your circuit. You will also answer the questions at the end of the lab. 

Specifically, you must address the following rubric criteria:   

  1. Develop code for all the specified functionalities. The goal of this criterion is for the code to result in the expected functionality. The commands (ON, OFF, EXIT, and QUIT) should operate as expected. In your video, show the terminal window and LED to clarify this.
  2. Create code that reads data from the serial port (UART). 
  3. Create code to control the LED on and off from the state machine. 
  4. Crate state machine documentation to describe the operation that matches the technical specifications. This should be completed as a draw.io file and saved as a PDF.
  5. Implement (in code) the state machine functionality described by the created documentation.
  6. Discuss the lab questions. Address all the questions thoroughly and thoughtfully, with supporting evidence from your work.
  7. Apply coding best practices in formatting, commenting, and functional logic. 

What to Submit

To complete this project, you must submit:  

  • A .py file (Python script file) that shows the source code you developed to program your Raspberry Pi
  • A short video of your device as it runs the code
  • A Word document with answers to the questions from the Milestone Two GPIO UART Lab Guide
  • A state machine diagram completed using draw.io and exported in PDF format
